\paragraph{Implementation details}{
Performing voxel-wise regressions over $19{,}801$ analysis voxels for data from $1{,}578$ subjects observed at $2$ visits is computationally intensive if carried out serially. In the current implementation, all model fitting was performed in \texttt{Python} from the raw UK Biobank lesion and covariate inputs. The jobs were run with $8$ worker processes, with BLAS threads capped at $1$ within each worker to avoid nested-thread oversubscription. RR-GEE was fitted using a chunked vectorised IRLS/Newton solver with a voxel chunk size of $256$, whereas RR-PGEE, OR-GEE, and OR-PGEE were fitted using L-BFGS optimisation. The resulting computational times and finite-output counts are summarised in Table~\ref{tab:ukb-computational-time}. The fitted outputs were written as coefficient, sandwich standard error, and Wald $z$-score maps for each covariate, together with convergence metadata.
}
